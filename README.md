# PontMás Alapítvány - Hivatalos Weboldal

A PontMás Vas Megyei Autista Gyermekekért Alapítvány megújult, Next.js (App Router) és Tailwind CSS alapú weboldala.

## Technológiai Stack
- **Keretrendszer:** Next.js (TypeScript)
- **Stílus:** Tailwind CSS
- **Ikonok:** Lucide React
- **Kiszolgálás:** Vercel (ajánlott)

## Helyi Futtatás
```bash
npm install
npm run dev
```

## Fejlesztési Elvek
A weboldal az autizmus-barát, letisztult és akadálymentes (a11y) design elveit követi, biztosítva a magas SEO teljesítményt és a gyors betöltési időt. Célunk, hogy a Vas vármegyei érintett családok és támogatók számára egy könnyen áttekinthető, modern platformot biztosítsunk.
