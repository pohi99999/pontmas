# Tech Stack: PontMás Alapítvány

## 1. Core Framework & Runtime
- **Runtime:** Node.js (LTS)
- **Framework:** Next.js 16 (App Router)
- **Library:** React 19 / React DOM 19
- **Language:** TypeScript 5

## 2. Styling & UI Components
- **CSS Framework:** Tailwind CSS v4 (`@tailwindcss/postcss`)
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Class Utilities:** `clsx`, `tailwind-merge`

## 3. Code Quality & Standards
- **Linter:** ESLint 9 with `eslint-config-next`
- **Type Checking:** TypeScript (`tsc --noEmit`)
- **Formatting & Configuration:** `tsconfig.json`, `postcss.config.mjs`

## 4. Hosting & Deployment
- **Deployment Platform:** Vercel / Node.js
- **CI/CD:** Git-based continuous deployment
